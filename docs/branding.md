# Branding — Cris das Passagens

## Objetivo da Marca

Transmitir confiança, modernidade e sensação de liberdade através de uma experiência visual premium voltada para turismo e viagens.

A marca deve parecer:

- moderna
- profissional
- confiável
- elegante
- acessível
- leve
- inspiradora

---

# Sensações que o website deve transmitir

- Liberdade
- Descoberta
- Viagem sem preocupação
- Segurança
- Experiência premium
- Atendimento confiável
- Facilidade

---

# Direção Visual

## Estilo

- Premium moderno
- Minimalista
- Clean
- Elegante
- Muito whitespace
- Layout respirado
- Visual confortável

---

# Inspirações

## Empresas

- Airbnb
- Stripe

- Booking
- Apple

## Características visuais desejadas

- Grandes imagens
- Seções amplas
- Tipografia forte
- Hierarquia clara
- Cards premium
- Sombras suaves
- Bordas arredondadas
- Grid limpo

---

# Tipografia

## Headings

- Grandes
- Fortes
- Poucas palavras
- Impactantes

## Textos

- Curtos
- Leves
- Muito legíveis
- Baixa densidade

---

# Uso de Imagens

As imagens devem transmitir:

- desejo de viajar
- liberdade
- destinos premium
- experiências inesquecíveis
- conforto
- aventura elegante

Priorizar:

- imagens amplas
- iluminação natural
- tons claros
- paisagens impactantes

Evitar:

- imagens genéricas demais
- excesso de filtros
- imagens poluídas

---

# Paleta de Cores

## Base

- Branco
- Off-white
- Cinza muito claro

## Primária

- Azul premium
- Azul turismo

## Accent

- Verde WhatsApp
- Azul claro
- Laranja suave opcional

---

# Componentes

## Cards

Devem possuir:

- bordas suaves
- imagens grandes
- hover elegante
- sombras leves
- bastante padding

---

# Botões

## Estilo

- modernos
- arredondados
- claros
- destaque visual forte
- animações suaves

---

# Navbar

A navbar deve:

- parecer leve
- ocupar pouco espaço
- possuir CTA destacado
- ficar sticky ao scroll
- possuir blur suave

---

# Hero Section

A hero é a seção mais importante do website.

Ela deve transmitir:

- desejo imediato
- viagem
- liberdade
- profissionalismo

Elementos importantes:

- headline forte
- imagem impactante
- CTA claro
- layout premium

---

# UX

## Experiência geral

A navegação deve parecer:

- leve
- rápida
- moderna
- confortável
- intuitiva

---

# Mobile

O mobile é prioridade máxima.

A experiência mobile deve:

- parecer premium
- possuir excelente spacing
- evitar excesso de conteúdo
- manter CTA sempre visível

---

# Regras Importantes

Evitar:

- excesso de texto
- excesso de cores
- elementos poluídos
- grids muito apertados
- sombras pesadas
- layouts antigos

Priorizar:

- simplicidade
- elegância
- clareza
- impacto visual
- legibilidade
- conversão

## Branding Atual

A empresa já utiliza azul #345ba7 como cor principal e você deve procurar mantê-lo.

O novo website deve modernizar essa identidade visual, mantendo reconhecimento da marca, mas com aparência muito mais premium, limpa e moderna.

# Tom da Marca

A comunicação visual e textual deve parecer:

- humana
- próxima
- acolhedora
- profissional
- inspiradora
- confiável

Evitar linguagem corporativa excessiva.

# Animações

As animações devem ser:

- sutis
- suaves
- rápidas
- elegantes

Evitar:

- animações exageradas
- efeitos chamativos
- excesso de motion

# Direção Geral

O website deve parecer uma empresa moderna de turismo em 2026, e não uma agência tradicional antiga.

Priorizar:

- experiência premium
- clareza
- confiança
- simplicidade moderna
- visual aspiracional
