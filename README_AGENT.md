# Projeto: Cris das Passagens

## Tipo de Projeto

Landing page premium moderna para agência de turismo.

## Objetivo

Modernizar completamente a presença digital da empresa.

O website deve:

- transmitir confiança
- parecer premium
- melhorar autoridade da marca
- gerar leads
- destacar destinos e serviços
- melhorar SEO
- funcionar perfeitamente no mobile

---

# Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide Icons

---

# Regras Técnicas

- Sempre usar Tailwind
- Nunca usar CSS inline
- Nunca criar código duplicado
- Mobile first
- SEO otimizado
- HTML semântico
- Acessibilidade AA mínima
- Componentes reutilizáveis
- Responsividade obrigatória
- Performance otimizada

---

# Código

- Componentes pequenos
- Código limpo
- Evitar overengineering
- Server Components quando possível
- Imports organizados

---

# Responsividade

O mobile é prioridade máxima.

Todas as páginas devem:

- funcionar perfeitamente em smartphones
- evitar overflow horizontal
- possuir spacing consistente
- manter excelente legibilidade

---

# SEO

Priorizar:

- metadata otimizada
- semantic HTML
- headings corretas
- performance
- acessibilidade
- sitemap
