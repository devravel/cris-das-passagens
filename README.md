# Cris das Passagens

Landing page premium para a agência de turismo **Cris das Passagens**.

Baseado no template interno `agency-base`, este repositório é um projeto independente — não está ligado ao remote do `agency-base`.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Documentação do projeto

- `README_AGENT.md` — regras e contexto para agentes de IA
- `docs/project-context.md` — objetivo, estrutura e requisitos
- `docs/branding.md` — identidade visual (a preencher)

## Repositório remoto
